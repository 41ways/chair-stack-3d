# 의자 쌓기 3D

의자를 하나씩 들어 받침대 위 탑에 얹는 3D 물리 게임. 돌리고 눕혀서 빈 구석에 끼워 넣고, 하나라도 받침대에서 떨어지면 끝.

[의자 쌓기](https://github.com/41ways/chair-stack)(2D)와 따로 만든 새 게임이다.

## 판

- 기본판: 똑같은 네모 의자만 나온다. 다리·좌판·등받이가 모두 직각인 사각 기둥(보드게임 의자 같은 모양), 색만 다르다
- 확장판: 모양이 다른 의자 다섯 종류(아래 표)

최고 기록은 판마다 따로 남는다.

## 하는 법

- 옮기기: 마우스를 움직이거나 한 손가락으로 끈다. 의자는 바로 아래 닿을 곳에서 10cm 위에 떠 있다
- 안내선: 가장 먼저 닿는 점과 바닥 쪽 다리 아래로 주황 선과 점
- 돌리기·눕히기: 조작판 버튼, 키보드 Q E(돌리기) · W S(앞뒤) · A D(옆). 한 번 누르면 15°, 누르고 있으면 계속 돈다. R은 바로 세우기
- 놓기: 클릭, Space, 놓기 버튼
- 핑: G(한글 ㅎ)를 누른 채 마우스를 밀어 고르고 떼면 마우스 자리에 찍힌다. 왼쪽 ? 물음표, 위 ! 위험, 오른쪽 → 간다, 아래 취소. 연속 3번까지, 3번 찍으면 5초 쉰다. 같이 할 때는 방 사람 모두에게 보인다. 자리는 화면 비율로 보내 다른 사람 화면의 같은 위치에 찍힌다(`ping.js`, 2D와 같은 파일)
- 시점: 오른쪽 드래그, 휠, 두 손가락, ◀ ▶ 버튼, 방향키

혼자 하기는 몇 개를 얹었는지가 기록. 한 화면 같이 하기는 2~4명이 번갈아 놓고, 떨어뜨린 사람이 진다.

## 온라인으로 같이 하기

방을 만들면 4자리 코드와 초대 링크(`?room=코드`)가 나온다. 최대 6명. 같이 하기 화면의 열린 방 목록에서 눌러 들어갈 수도 있다.

- 우리 서버는 없다. 브라우저끼리 WebRTC로 바로 잇고, 처음 서로 찾는 것만 PeerJS 공용 중계(0.peerjs.com)를 거친다
- 방장 화면이 물리를 계산해 50ms마다 탑 전체 자리를 보낸다. 참가자는 그 자리로 의자를 옮겨 그린다
- 차례인 참가자는 자기 화면에서 의자를 옮기고 놓으면 그 자세를 방장에게 보낸다
- 열린 방 목록(`lobby.js`)도 서버가 없다. 같이 하기 화면을 연 브라우저 중 먼저 온 하나가 PeerJS 이름 `chairstack3d-lobby` 를 잡아 목록을 맡고, 방장들은 방 정보를 거기에 올린다. 맡은 사람이 나가면 남은 사람 중 하나가 이어받는다. 2D와 같은 파일
- 방장이 나가면 방이 닫힌다. 방장 창이 뒤로 가면 느려진다
- 회사·학교처럼 막힌 네트워크에서는 연결이 안 될 수 있다

## 확장판 의자

| 의자 | 특징 |
| --- | --- |
| 나무 의자 | 등받이 때문에 앉는 자리가 좁다 |
| 학교 의자 | 가볍고 다리가 가는 쇠파이프 |
| 네모 스툴 | 윗면이 작고 다리가 벌어져 있다 |
| 팔걸이 소파 | 무겁고 넓어서 받침이 된다 |
| 긴 벤치 | 1m 길이라 두 자리를 잇는다 |

## 만든 방식

- 화면: three.js 0.160.0, 물리: Rapier 0.12.0(rapier3d-compat), 연결: PeerJS 1.5.4. 모두 jsDelivr에서 받는다
- 크기는 미터, 중력 9.81. 1/120초 단위로 계산하고 빠른 물체는 연속 충돌 검사
- 의자는 상자와 가는 막대로만 판정한다. Rapier 원기둥은 접촉이 한 점이라 받침 위에서 미끄러지고, 다각기둥은 윗면이 삼각형으로 쪼개져 위에 얹은 것이 계속 흔들려서 받침대·스툴 윗면을 네모로 했다
- 놓을 높이는 의자 부품마다 아래로 모양을 쏘아(shape cast) 가장 먼저 닿는 곳으로 정한다. 안내선 하나는 그 맞닿는 점(witness2)
- 떨어짐 판정은 의자 무게중심이 받침대 윗면보다 15cm 아래로 내려갔을 때
